# 命運大轉盤｜隨機抽籤工具

一個單頁的網頁抽籤轉盤。不需要安裝、不需要建置，只要一個 `index.html`，用瀏覽器開啟就能使用。

線上版（啟用 GitHub Pages 後）：<https://profleeys.github.io/fate-wheel/>

## 功能

**轉盤**
- 以 HTML5 Canvas 繪製，扇形角度依機率動態計算，相鄰色塊不會重複顏色。
- 文字沿半徑方向排列，過長會自動以「…」省略。
- 頂部有固定指針，轉動時會隨刻度輕輕彈動。
- 點擊中心「GO」或「開始抽籤」，約 4.5–6 秒、轉 6–10 圈後緩慢減速，停在預先決定的結果上。
- 轉動期間，除了靜音與歷史紀錄按鈕，其餘輸入與按鈕都會停用，避免重複觸發。

**機率**
- 每個選項都有自己的機率百分比，總和固定為 100%，預設為均分。
- 可輸入數字或拖動滑桿調整，其他選項會按原本比例自動補滿剩下的機率。
- 新增、刪除選項或啟用淘汰模式後，機率會自動重新分配。
- 「均分重設」一鍵回到平均機率。

**音效與回饋**
- 全部使用 Web Audio API 即時合成，沒有任何外部音檔。
- 轉盤越過刻度時發出「噠噠」齒輪聲，抽中時播放得獎音效，可隨時靜音。
- 抽中時有全螢幕彩帶動畫與中獎視窗。

**名單管理**
- 單筆新增、刪除，直接修改選項名稱，用 − / + 快速增減個數。
- 多行批量貼上（每行一個選項），可選擇加入或取代全部。
- 快速模板：今天吃什麼？、聚會懲罰、數字 1-8。
- 淘汰模式：抽中後自動移除該選項。
- 歷史紀錄抽屜，顯示抽中的項目與時間。
- 名單與設定自動存在瀏覽器的 `localStorage`。

**介面**
- 預設深色石板配色與玻璃擬態面板，系統為淺色主題時自動切換淺色。
- 響應式佈局：桌面左邊轉盤、右邊控制面板，手機上下排列。

## 使用方式

直接用瀏覽器開啟 `index.html` 即可。頁面需要網路，因為 React、Tailwind CSS 與字型是從 CDN 載入。

也可以用本機伺服器預覽：

```bash
python3 -m http.server 8000
# 然後開啟 http://localhost:8000
```

## 部署到 GitHub Pages

1. 到 repo 的 **Settings → Pages**。
2. **Source** 選擇 *Deploy from a branch*。
3. **Branch** 選 `main`，資料夾選 `/ (root)`，按 Save。
4. 等待一兩分鐘，網站就會出現在上方的線上版網址。

其他靜態網站服務（Netlify、Cloudflare Pages、Vercel）也可以直接部署，不需要設定建置指令。

## 技術

- React 18（UMD 版本，由 cdnjs 載入）
- Babel Standalone（在瀏覽器內編譯 JSX）
- Tailwind CSS（Play CDN）與少量自訂 CSS 變數
- HTML5 Canvas、Web Audio API
- 圖示為內嵌的 Lucide SVG 路徑
- 字型：Noto Sans TC、DM Mono（Google Fonts）

## 資料與隱私

名單、設定與歷史紀錄只存在你自己的瀏覽器裡，不會上傳到任何伺服器，也不會跨裝置同步。清除瀏覽器網站資料會一併清除這些內容。

## 已知限制

- 程式在瀏覽器內即時編譯，首次載入比預先建置的版本稍慢；Tailwind 的 CDN 版本也不建議作為長期的正式環境使用。
- 單一選項最低機率約 0.1%，一項被調到接近 100% 時，其他項可能被壓到更低。
- 選項名稱最長 40 個字，最多 100 個選項。
